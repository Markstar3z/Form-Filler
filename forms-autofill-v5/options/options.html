1. Quick answers (free, local, instant)

How matching works
  • Keywords are comma-separated phrases. If a question contains one, that row is used. Longer phrases win.
  • A keyword starting with = only matches when the whole question is exactly that (e.g. =name).
  • Choice questions: the value must match an option's text (e.g. Male). For checkboxes, separate several values with ;.
  • Dates: write 31/12/1999 (day first) or 1999-12-31.

Keep it to what forms normally ask (background, education, experience, skills): no ID numbers or sensitive details. The quick-answer table above never leaves your browser.
What gets sent only when you press the AI button: your About me plus, for the unanswered questions only, the question text, description, type and options. Not sent: your quick-answer table, the page's URL, anything already typed in, or questions about passwords/codes/IDs.
